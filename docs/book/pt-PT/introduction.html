OpenCrabs

Introduction

O OpenCrabs é um agente de orquestração de IA auto-hospedado e agnóstico de provider que corre como um único binário Rust. Automatiza o teu terminal, browser, channels (Telegram/Discord/Slack/WhatsApp/Trello) e codebase, respeitando a tua privacidade e mantendo-te no controlo.

6,997 testes abrangendo providers, ferramentas, channels, TUI, self-healing e automação de browser.

O Que Distingue o OpenCrabs

Zero Telemetria, Nem por Opção

  • O OpenCrabs nunca liga para casa. Nunca. Sem analytics, sem tracking, sem estatísticas de utilização, sem logs remotos, sem relatórios de falhas
  • As tuas conversas, ferramentas, memória, configuração e chaves de API nunca saem da tua máquina
  • O único tráfego de saída é o que inicias explicitamente: chamadas a APIs de LLM, pesquisas web, comandos GitHub, automação de browser
  • Não é uma checkbox de política de privacidade: não há código de telemetria para desativar, nenhuma flag de opt-out, nenhum serviço de analytics para bloquear. Simplesmente não há nada para enviar

Agnóstico de Provider por Concepção

  • 16 providers integrados + Custom OpenAI Compatible: Anthropic Claude, OpenAI, Gemini, Xiaomi MiMo, OpenRouter, Qwen (DashScope), MiniMax, Ollama, z.ai GLM, GitHub Copilot, Codex, Codex CLI, OpenCode, OpenCode CLI, Moonshot AI (Kimi), Command Code CLI
  • Integração CLI nativa — usa o Claude Code CLI, OpenCode CLI, Codex CLI e Command Code CLI como providers sem chaves de API
  • Cadeia de fallback persistente — failover automático em rate limits ou erros, persistência com noção de estado que sobrevive a reinícios
  • Prompt caching em Anthropic, OpenRouter, Gemini e Qwen DashScope reduz custos até 95%
  • Override da janela de contexto — limita ou expande o contexto de qualquer model via config
  • Xiaomi MiMo — mais de 30 models incluindo a série de reasoning MiMo, provider com chave
  • Moonshot AI (Kimi) — endpoints do plano API (api.moonshot.ai) e do plano Coding (api.kimi.com), config de reasoning-effort, janela de contexto por nível de plano

Multi-Agent Orchestration

  • As sessions são agentes totalmente isolados — cada uma com o seu próprio brain, provider, model, diretório de trabalho e histórico
  • Sub-agentes tipados: general, explore, plan, code, research com acesso a ferramentas adaptado
  • Orquestração de equipas: team_create, team_broadcast, team_delete para workflows coordenados
  • Overrides de provider/model por chamada — mistura models entre equipas (planear com GLM, programar com Deepseek, rever com Kimi)
  • Protocolo A2A — gateway JSON-RPC 2.0 para comunicação agente-a-agente

Descoberta de Diretivas de Projeto (v0.3.59)

O OpenCrabs descobre automaticamente ficheiros de regras que outras ferramentas de codificação por IA deixam num repo. Aponta o agente para qualquer repositório (via /cd, um workspace de channel, ou lançando dentro de um) e ele pesquisa as convenções enviadas pelo Claude Code, Cursor, Windsurf, Cline, Gemini CLI, GitHub Copilot, OpenCode e o standard entre ferramentas AGENTS.md. Sem config, sem passo de importação.

Início Rápido

# Instalar (Linux/macOS)
ARCH=$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/')
OS=$(uname -s | tr A-Z a-z)
TAG=$(command -v jq >/dev/null 2>&1 && curl -s https://api.github.com/repos/adolfousier/opencrabs/releases/latest | jq -r .tag_name || curl -s https://api.github.com/repos/adolfousier/opencrabs/releases/latest | grep -o '"tag_name":"[^"]*"' | cut -d'"' -f4)
curl -fsSL "https://github.com/adolfousier/opencrabs/releases/download/${TAG}/opencrabs-${TAG}-${OS}-${ARCH}.tar.gz" | tar xz
./opencrabs

# Ou via Cargo (requer Rust 1.94+)
cargo install opencrabs --locked

Auto-update ativado por defeito. Desativa com [agent] auto_update = false em ~/.opencrabs/config.toml.
