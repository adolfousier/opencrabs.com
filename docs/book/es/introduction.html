OpenCrabs

Introduction

OpenCrabs es un agente de orquestación de IA autoalojado y agnóstico de proveedor que funciona como un único binario Rust. Automatiza tu terminal, navegador, canales (Telegram/Discord/Slack/WhatsApp/Trello) y código base, respetando tu privacidad y manteniéndote en control.

6,997 tests cubriendo proveedores, herramientas, canales, TUI, auto-reparación y automatización de navegador.

Qué Hace Diferente a OpenCrabs

Cero Telemetría, Ni Siquiera Opt-In

  • OpenCrabs no llama a casa. Nunca. Sin analíticas, sin rastreo, sin estadísticas de uso, sin logs remotos, sin informes de fallos
  • Tus conversaciones, herramientas, memoria, configuración y claves API nunca salen de tu máquina
  • El único tráfico saliente es el que tú inicias explícitamente: llamadas a APIs de LLM, búsquedas web, comandos de GitHub, automatización de navegador
  • No es una casilla de política de privacidad: no hay código de telemetría que desactivar, ningún flag de opt-out, ningún servicio de analíticas que bloquear. Simplemente no hay nada que enviar

Agnóstico de Proveedor por Diseño

  • 16 proveedores integrados + Custom OpenAI Compatible: Anthropic Claude, OpenAI, Gemini, Xiaomi MiMo, OpenRouter, Qwen (DashScope), MiniMax, Ollama, z.ai GLM, GitHub Copilot, Codex, Codex CLI, OpenCode, OpenCode CLI, Moonshot AI (Kimi), Command Code CLI
  • Integración CLI nativa — usa Claude Code CLI, OpenCode CLI, Codex CLI y Command Code CLI como proveedores sin claves API
  • Cadena de fallback persistente — conmutación automática por rate limits o errores, persistencia consciente de salud que sobrevive a reinicios
  • Prompt caching en Anthropic, OpenRouter, Gemini y Qwen DashScope reduce costes hasta un 95%
  • Override de ventana de contexto — limita o amplía el contexto de cualquier modelo vía config
  • Xiaomi MiMo — 30+ modelos incluyendo la serie de razonamiento MiMo, proveedor con clave
  • Moonshot AI (Kimi) — endpoints del plan API (api.moonshot.ai) y del plan Coding (api.kimi.com), config de reasoning-effort, ventana de contexto por nivel de plan

Multi-Agent Orchestration

  • Las sesiones son agentes totalmente aislados — cada una con su propio brain, proveedor, modelo, directorio de trabajo e historial
  • Sub-agentes tipados: general, explore, plan, code, research con acceso a herramientas a medida
  • Orquestación de equipos: team_create, team_broadcast, team_delete para workflows coordinados
  • Overrides de proveedor/modelo por llamada — mezcla modelos entre equipos (planear con GLM, programar con Deepseek, revisar con Kimi)
  • Protocolo A2A — gateway JSON-RPC 2.0 para comunicación agente-a-agente

Descubrimiento de Directivas de Proyecto (v0.3.59)

OpenCrabs descubre automáticamente los archivos de reglas que otras herramientas de código con IA dejan en un repo. Apunta el agente a cualquier repositorio (vía /cd, un workspace de canal, o lanzándolo dentro de uno) y escanea las convenciones traídas por Claude Code, Cursor, Windsurf, Cline, Gemini CLI, GitHub Copilot, OpenCode y el estándar multi-herramienta AGENTS.md. Sin config, sin paso de importación.

Inicio Rápido

# Install (Linux/macOS)
ARCH=$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/')
OS=$(uname -s | tr A-Z a-z)
TAG=$(command -v jq >/dev/null 2>&1 && curl -s https://api.github.com/repos/adolfousier/opencrabs/releases/latest | jq -r .tag_name || curl -s https://api.github.com/repos/adolfousier/opencrabs/releases/latest | grep -o '"tag_name":"[^"]*"' | cut -d'"' -f4)
curl -fsSL "https://github.com/adolfousier/opencrabs/releases/download/${TAG}/opencrabs-${TAG}-${OS}-${ARCH}.tar.gz" | tar xz
./opencrabs

# Or via Cargo (requires Rust 1.94+)
cargo install opencrabs --locked

Auto-actualización activada por defecto. Desactívala con [agent] auto_update = false en ~/.opencrabs/config.toml.
